# 📱 Mobile Price Prediction - Machine Learning Project

This project predicts mobile phone price ranges using machine learning algorithms based on device specifications.

---

## 🔍 Problem Statement
Classify mobile phones into price ranges (0–3) using features like RAM, battery power, camera, and display.

---

## 🤖 Models Used
- Decision Tree
- Random Forest
- KNN
- Logistic Regression
- XGBoost
- Voting Classifier
- Bagging Classifier
- Stacking Classifier

---

## 🏆 Best Model
- Stacking / Bagging Classifier  
- Accuracy: 92.6%

---

## 📊 Evaluation
- Cross-validation used for model evaluation
- Confusion matrix analysis
- Accuracy comparison across models

---

## 📈 Key Insights
- RAM is the most important feature
- Ensemble models performed best
- KNN also showed strong performance

---

## 🛠 Tech Stack
Python, Pandas, NumPy, Scikit-learn, XGBoost, Matplotlib, Seaborn
